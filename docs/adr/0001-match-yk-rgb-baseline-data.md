# Match the yk RGB baseline data protocol

For the first comparable per-task Cosmos Policy result across all 26 tasks, use each task's 100 matched HDF5 episodes from `replay-generalization` and all four RGB policy cameras. Audit each task against yk's source by file identity or hash before training; task 03 is the first verified match. Use current active-joint state and the full scene description as additional inputs. Exclude depth, tactile, object-state, box, and occupancy inputs from this RGB baseline, even when the benchmark offers them. The yk GR00T baseline used the four-camera RGB and proprioception protocol; holding out demonstrations or omitting a camera would change the comparison and require costly retraining.

Compute normalization statistics per task from those training episodes, excluding homing and invalid frames. Train separate task checkpoints to predict 16 absolute active-joint targets; execute all 16 at 20 Hz before querying the policy again, matching yk's control cadence. Measure outcomes with separate closed-loop simulation episodes rather than a demonstration validation split. Smaller camera configurations may be used for development checks, but are not the reported baseline. Match data and evaluation protocol, then measure Cosmos training speed and success-rate convergence to choose its update budget; a fixed 20,000-update limit would not equalize compute between models.
