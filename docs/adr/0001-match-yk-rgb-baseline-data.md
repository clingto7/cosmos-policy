# Match the yk RGB baseline data protocol

For the first comparable per-task Cosmos Policy result, train on all 100 Bench2Dex RGB demonstrations per task and use all four RGB cameras. The yk GR00T baseline used this protocol; holding out demonstrations or omitting a camera would change the comparison and require costly retraining. Predict 16 absolute active-joint targets and execute all 16 at 20 Hz before querying the policy again, matching yk's control cadence. Measure outcomes with separate closed-loop simulation episodes rather than a demonstration validation split. Smaller camera configurations may be used for development checks, but are not the reported baseline. Match data and evaluation protocol, then measure Cosmos training speed and success-rate convergence to choose its update budget; a fixed 20,000-update limit would not equalize compute between models.
