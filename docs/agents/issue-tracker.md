# Issue tracker: GitHub

Issues and specs live in this repository's GitHub Issues. Use `gh` from this clone.
Read issues and comments before acting; publish tickets as GitHub issues.
PRs as a triage request surface: no.

For wayfinding, use a `wayfinder:map` issue with child issues. Record blocking
dependencies through GitHub issue dependencies when available, otherwise in
a `Blocked by: #...` line. Claim a ticket by assignment before work.
